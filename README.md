# 💬 ChatAPP

ChatAPP is an online chat application built with React and NodeJS + ExpressJS, designed as a personal learning project.

**Note:** _This website was built solely for learning purposes and is not intended for real-world use. Please do not enter any personal or sensitive information._

![ChatAPP Preview](https://i.ibb.co/hFfpsbkJ/chatapp-preview.png)

---

## 🛠️ Setup Steps

1. Clone the repository:

```
git clone https://github.com/mhergharibyan550/chat-app.git
```

2. Navigate to the root and `/frontend` folders individually and install dependencies for each folder:

```
npm install
```

3. Review `.env.example` and create a `.env` file in the root folder with the required values.

---

## 🚀 Usage

1. Navigate to the root directory and build the project:

```
npm run build
```

2. Start the application:

```
npm run start
```
